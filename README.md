# Полиця переглядів

Особистий трекер аніме, фільмів і серіалів: статус, сезон і серія, власна
оцінка 1–10, посилання «де дивлюсь», нотатка — і список рекомендацій, яким
можна поділитися одним посиланням.

**Відкрити:** https://ledron-mf-dude.github.io/MyWatchShelf/

Користуватися може будь-хто: у кожного своя полиця. Свого сервера немає,
адмініструвати нікого не треба.

## Як це влаштовано

```
браузер (телефон, ПК)                         чужі сервіси, без нашого сервера
┌───────────────────────────┐
│ статична сторінка         │──── пошук, оцінка IMDb, опис, серії ──▶ Cinemeta
│ (GitHub Pages)            │──── постери ──────────────────────────▶ metahub
│                           │
│ localStorage — правда     │◀─── вхід через Google ────────────────▶ Firebase Auth
│ цього пристрою            │◀──▶ users/{uid}/entries/{ttID} ───────▶ Firestore
│                           │───▶ public/{uid} (рекомендації) ──────▶ Firestore
└───────────────────────────┘
```

* **Сторінка статична.** Її роздає GitHub Pages; збирати нічого не треба —
  звичайні ES-модулі.
* **Довідкові дані** (пошук у реальному часі, назва, рік, оцінка IMDb, опис,
  жанри, кількість серій у сезонах) дає [Cinemeta](https://github.com/Stremio/stremio-addon-sdk)
  — відкритий каталог, ключований ID з IMDb (`tt…`). Ключа не просить і
  пускає до себе браузерну сторінку. Сам IMDb відкритого API не має і
  сторінку з чужого домену до себе не пускає, тому напряму до нього не ходимо;
  з картки є посилання на сторінку тайтла на IMDb.
* **Список живе в браузері** (localStorage) — тож усе працює одразу, без
  входу й без мережі.
* **Синхронізація** — за бажанням: «Увійти через Google». Тоді записи лягають
  у Firestore, у гілку цієї людини, і з’являються на всіх її пристроях.
  Правила в `firestore.rules` пускають кожного лише до свого.
* **Злиття** — по одному запису: свіжіша правка (`updated`) перемагає;
  довідкове з IMDb їде окремою міткою (`metaAt`), щоб оновлення опису на ПК
  не затерло оцінку, поставлену з телефона без мережі. Видалене лишається
  міткою `deleted`.

## Рекомендації

У картці запису — «Додати в рекомендації» і кілька слів, чому варто.
Меню `···` → «Поділитись рекомендаціями» дає посилання:

| Хто ділиться | Посилання | Як поводиться |
|---|---|---|
| увійшов через Google | `…/#u=<uid>` | постійне: завжди показує свіжий список |
| без входу | `…/#r=<список>` | знімок: список стиснуто й зашито просто в посилання |

Гість бачить назви, оцінки автора й коментарі та може одним дотиком покласти
запис на власну полицю. Посилання «де дивлюсь» і нотатки **не передаються**.

## Додавання

Поле «Додати» розуміє:

* назву будь-якою мовою (`відьмак`, `sousou no frieren`) — список оновлюється,
  поки друкуєш;
* посилання або ID з IMDb (`https://www.imdb.com/title/tt22248376/`);
* посилання сайту, де дивишся: назву вгадає з адреси, а саме посилання
  збереже як «де дивлюсь».

## Телефон

Відкрий сторінку в Chrome або Safari → «Додати на головний екран». Далі це
звичайний застосунок: відкривається без мережі й пам’ятає останній стан.

## Файли

```
index.html, styles.css
js/
  logic.js    чиста логіка: злиття, «+1 серія», фільтри, кодування посилань
  meta.js     каталог (пошук і довідкові дані)
  store.js    сховище пристрою
  cloud.js    Firebase: вхід, синхронізація, публікація рекомендацій
  config.js   веб-конфіг Firebase (не секрет; null — без хмари)
  app.js      інтерфейс
sw.js, manifest.webmanifest, icon-*.png   застосунок на телефоні
firestore.rules                           хто що може читати й писати
tests/logic.test.mjs                      node --test tests/
tools/icons.mjs                           перемальовує іконки
```

Локальний запуск: `python -m http.server 8765` у теці проєкту →
http://localhost:8765 (модулі з подвійного кліку по файлу браузер не пустить).

## Власна копія

1. Форкни репозиторій і ввімкни GitHub Pages (гілка `main`, корінь).
2. Щоб була синхронізація, створи безкоштовний проєкт у
   [Firebase](https://console.firebase.google.com): Authentication → Google,
   Firestore Database, у Authentication → Settings → Authorized domains додай
   свій `<нік>.github.io`, а правила візьми з `firestore.rules`.
3. Веб-конфіг проєкту встав у `js/config.js`.

Без кроків 2–3 застосунок працює в межах одного пристрою, а рекомендації
діляться посиланням-знімком.

## Приватність

* Приватний список бачить лише власник (правила Firestore).
* Рекомендації за посиланням бачить кожен, хто має посилання.
* Усе, що потрапляє в `href`, проходить через `safeUrl()` — лише `http(s)`.
* Дані з хмари, з імпорту й з посилань проходять `sanitize()` / `cleanRecs()`
  і в сторінку вставляються лише екранованими.
