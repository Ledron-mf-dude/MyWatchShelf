# Ovion

Особистий трекер аніме, серіалів і фільмів — у вигляді стрімінгового сервісу,
але про *твій* перегляд: на чому зупинився, що оцінив, де дивишся і що радиш
друзям.

**Відкрити:** https://ledron-mf-dude.github.io/MyWatchShelf/

Інтерфейс двома мовами: англійська за замовчуванням, українська — перемикачем
у меню акаунта («Language / Мова»).

Користуватися може будь-хто: у кожного свій список. Власного сервера немає,
адмініструвати користувачів не треба.

## Що вміє

| Розділ | Що там |
|---|---|
| **Головна** | «Продовжити перегляд» з великим банером і кнопкою «Серію переглянуто», власний топ з місцями, плани, популярне зараз із каталогу |
| **Бібліотека** | Плитка постерів або список; фільтри за типом, статусом, жанрами; пошук (зокрема за українською назвою жанру); сім сортувань |
| **Каталог** | Популярні серіали, аніме й фільми з фільтром за жанром і роком; додавання на полицю одним дотиком |
| **Календар** | Нові серії того, що дивишся: що вийшло цього тижня, що скоро і скільки серій чекає; смужка найближчого — на головній |
| **Статистика** | Години перегляду, кількість серій, середня оцінка, розподіл оцінок, улюблені жанри, «де я не згоден з IMDb» |
| **Картка запису** | Статус, сезони й сітка серій, оцінка 1–10, посилання «де дивлюсь», нотатка, рекомендація з коментарем, опис, акторський склад, трейлер |
| **Пошук** (`/` або `Ctrl+K`) | Одне поле шукає і на полиці, і в каталозі; розуміє назву будь-якою мовою, посилання чи ID з IMDb, посилання сайту, де дивишся |
| **Рекомендації й добірки** | Список «раджу друзям» та іменовані добірки, кожна зі своїм посиланням; гість бачить оцінки й коментарі автора, збіг смаків зі своїм списком і забирає тайтли собі |
| **Що подивитись сьогодні?** | Випадковий вибір із планів за тривалістю, типом і жанром |
| **Картка-підсумок** | Зображення з годинами перегляду, кількістю серій і найвищими оцінками — завантажити чи надіслати |

Ще: темна й світла теми, робота без мережі, встановлення на головний екран
телефона, скасування останньої дії («Повернути» після видалення чи «+1 серія»),
резервна копія у файл, показ на прикладі (14 готових записів для демонстрації).

## Як це влаштовано

```
браузер (телефон, ПК)                         чужі сервіси, без нашого сервера
┌───────────────────────────┐
│ статична сторінка         │──── пошук, каталог, оцінка IMDb, ─────▶ Cinemeta
│ (GitHub Pages)            │     опис, серії по сезонах
│                           │──── постери й фони ───────────────────▶ metahub
│ localStorage — правда     │
│ цього пристрою            │◀─── вхід через Google ────────────────▶ Google + Firebase Auth
│                           │◀──▶ users/{uid}/entries/{ttID} ───────▶ Firestore
│                           │───▶ public/{uid} (рекомендації) ──────▶ Firestore
└───────────────────────────┘
```

* **Сторінка статична** — звичайні ES-модулі, без збирання й залежностей.
* **Довідкові дані** дає [Cinemeta](https://github.com/Stremio/stremio-addon-sdk) —
  відкритий каталог, ключований ID з IMDb (`tt…`). Ключа не просить і пускає до
  себе браузерну сторінку. Сам IMDb відкритого API не має; з картки є
  посилання на сторінку тайтла на IMDb.
* **Список живе в браузері**, тож усе працює одразу — без входу й без мережі.
* **Синхронізація** — за бажанням: «Увійти через Google». Записи лягають у
  Firestore, у гілку цієї людини. Правила (`firestore.rules`) пускають кожного
  лише до свого; рекомендації читає будь-хто за посиланням.
* **Вхід** — звичайним переходом сторінки до Google і назад (без спливних
  вікон), тому працює і в мобільних браузерах, і в застосунку з головного
  екрана.
* **Злиття** — по одному запису: свіжіша правка (`updated`) перемагає;
  довідкове з каталогу їде окремою міткою (`metaAt`), щоб оновлення опису на
  ПК не затерло оцінку, поставлену з телефона без мережі. Видалене лишається
  міткою `deleted`.

### Рекомендації

| Хто ділиться | Посилання | Як поводиться |
|---|---|---|
| увійшов через Google | `…/#u=<uid>` | постійне: завжди показує свіжий список |
| без входу | `…/#r=<список>` | знімок: список стиснуто й зашито просто в посилання |
| добірка (з входом) | `…/#u=<uid>&l=<назва>` | постійне посилання на одну добірку |

Усе, що позначено «раджу» або додано в добірку, потрапляє в публічний список
людини: його бачить кожен, хто має будь-яке її посилання. Застосунок каже про
це при створенні добірки й у картці запису.

Посилання «де дивлюсь», нотатки й імʼя з Google-акаунта **не передаються**;
підпис у рекомендаціях людина вписує сама.

## Безпека й приватність

* Content-Security-Policy: скрипти лише свої та SDK Firebase; зʼєднання лише
  з каталогом і Google; жодних фреймів і форм.
* Усе, що потрапляє в `href`, проходить `safeUrl()` — тільки `http(s)`.
* Дані з хмари, імпорту й посилань проходять `sanitize()` / `cleanRecs()` і
  вставляються в сторінку лише екранованими.
* Розпакування посилання-знімка має межу розміру (захист від «бомби»).
* Вхід захищено одноразовим `state`; токен одразу прибирається з адреси.
* На спільному пристрої список одного акаунта не дістається іншому.

## Розробка

```
python -m http.server 8765     # http://localhost:8765
npm test                       # тести чистої логіки (Node 20+, без залежностей)
```

## Власна копія

1. Форкни репозиторій і ввімкни GitHub Pages (гілка `main`, корінь).
2. Створи безкоштовний проєкт у [Firebase](https://console.firebase.google.com):
   Authentication → Google, Firestore Database; у Authentication → Settings →
   Authorized domains додай свій `<нік>.github.io`; правила — з `firestore.rules`.
3. Веб-конфіг проєкту й ID веб-клієнта Google встав у `js/config.js`.
4. У Google Cloud Console → Credentials → «Web client (auto created by Google
   Service)» додай адресу сайту в **Authorized redirect URIs**.

Без кроків 2–4 застосунок працює в межах одного пристрою, а рекомендації
діляться посиланням-знімком.

## Відомі обмеження

* Назви й описи тайтлів — мовою каталогу (англійською) в обох мовах
  інтерфейсу; жанри, статуси й усе решта перекладаються.
* Каталог — сторонній безкоштовний сервіс без гарантій доступності; він
  ізольований у `js/meta.js`, тож джерело можна замінити, не чіпаючи решти.
* Години перегляду — оцінка: коли тривалість серії невідома, береться типова.
