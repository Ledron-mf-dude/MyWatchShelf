# Тест режиму друзів: сценарії та стан

Тест проходять агенти-тестувальники через інтерфейс, кожен — окрема «людина»
на своїй адресі `http://<імʼя>.localhost:8769/`. Вхід і база — локальний
емулятор Firebase з правилами `firestore.rules`, тож Google не потрібен.

## Як підняти середовище

1. Емулятор (тримає дані лише в памʼяті — після зупинки все зникає):
   `cd E:\MyBoardGames\MyWatchShelf; npx -y firebase-tools@latest emulators:start --only auth,firestore --project mywatchshelf`
2. Тестовий сервер сайту: `node tools/dev-server.mjs 8769`
   (у Claude — конфігурація `watchshelf-emu` у `.claude/launch.json`).
3. Людина входить так: відкрити `http://<імʼя>.localhost:8769/?emu=<імʼя>`,
   далі кнопка акаунта → «Увійти через Google».

## Сценарії

| Файл | Роль |
|---|---|
| `qa-common.md` | спільні правила для всіх тестувальників і формат звіту |
| `qa-alice-1.md` | Аліса — власниця з входом, фаза 1: добірки, посилання |
| `qa-bogdan.md` | Богдан — друг, що входить, оцінює і ділиться у відповідь |
| `qa-guest.md` | гість без входу, потім Віка — друга оцінювачка |
| `qa-links.md` | посилання Аліси з останнього прогону (дійсні, лише поки живий той самий емулятор) |

Фаза 2 Аліси (ще не записана окремим файлом, запускається після Богдана й Віки):
таблиця «Друзі» (стовпці Богдана й Віки, оцінки збігаються з їхніми звітами,
«Сер.»), позначка «нове» на «Друзях» і її зникнення, блок друзів у картці
тайтла, відкрити посилання Богдана й натиснути «Запамʼятати», ввімкнути
«Друзі бачать оцінки одне одного» → Богдан і Віка перевіряють, що бачать
оцінки одне одного; вимкнути → перестають бачити; сховати/повернути друга,
видалити його рекомендації.

## Зауваження з двох завершених проходів

Вади:
1. Нова добірка з назвою, що вже є, мовчки зливається зі старою: записи
   обʼєднуються, умови замінюються, попередження немає.
2. У діалозі збирання будь-який чип умови стирає позначене вручну
   (позначив 5 → увімкнув і вимкнув «Фільми» → «Вибрано: 0»).
3. Телефон (375 px): діалог «Поділитись» вилазить за правий край (поле
   посилання, смуга постерів, текст); у діалозі збирання горизонтальна прокрутка.
4. Текст видалення «посилання перестане працювати» неправдивий для знімків
   (без входу), а з входом — лише доки назву не використають знову.

Незручності:
5. Добірку не можна перейменувати чи відредагувати; «Зібрати список» у
   діалозі добірки відкриває порожню нову. Три назви одного: «Нова добірка» /
   «Зібрати добірку» / «Зібрати список».
6. Текст живого посилання обіцяє «завжди свіжий список», але добірка за
   умовами оновлюється лише кнопкою, а ручна — ніколи; позначки «застаріла» немає.
7. Добірка за умовами бере все з полиці, зокрема «У планах» без оцінки —
   і воно йде другові як рекомендація.
8. Рік: одне поле «від» означає рівно цей рік (відкритий діапазон неможливий);
   приймає літери; застосовується лише після виходу з поля; обернений
   діапазон лишається оберненим на картці.
9. Назва мовчки обрізається до 40 символів; Enter у полі назви не зберігає.
10. Власник за «Як бачить гість» бачить «100% збіг смаків» із самим собою;
    відкривається в тій самій вкладці.
11. «Копіювати» без доступу до буфера мовчки відкриває діалог «Поділитись».
12. Перемикач «Друзі бачать оцінки одне одного» схований у «Керувати
    друзями»; «друзі» насправді — будь-хто з посиланням, хто ввійшов.
13. Заголовок «Друзі · 0 тайтлів» рахує тайтли, а не друзів; порожній стан
    згадує «Запамʼятати», не кажучи, де це.
14. На телефоні «Друзі» й «Рекомендації» лише в меню акаунта.
15. Після «Сформувати знову» сам відкривається діалог «Поділитись»; у
    підтвердженні лише кількості, без назв.
16. Перемикач на картці: «Додати в рекомендації» ↔ «Раджу друзям» — різні
    слова для одного; кнопка без підпису для екранного читача.
17. «Сер.» у таблиці друзів — середнє без моєї оцінки, підпис цього не каже.
18. Без входу дані живуть лише в цьому браузері — про це ніде не сказано.

Дрібниці:
19. «ДОБІРКА ВІД АЛІСА» — імʼя не відмінюється.
20. «збіг · твоя 7» при авторовій 8.
21. Діалог прикладу обіцяє 14 записів, додає 8 (дублікати) без пояснення.
22. Завершене аніме: «0 з 89 серій · 100%».
23. У діалозі збирання умови займають майже всю висоту — видно один рядок списку.
24. Діалог «Поділитись» змінює ширину між вкладками; смуга постерів обрізає без «+N».
25. Картка тайтла перемальовується цілком на перемикач «раджу» (постер блимає).
26. Картки добірок за абеткою, а не за часом створення.

Не перевірено в жодному проході: справжнє копіювання в буфер (панель
браузера його не дозволяє); усе, що стосується оцінок друга, таблиці
«Друзі» з даними й перемикача видимості.
