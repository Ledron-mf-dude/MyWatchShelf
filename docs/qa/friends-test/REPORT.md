# Тест режиму друзів — підсумок (2026-11-26)

Пройшли п'ять ролей через інтерфейс, на локальному емуляторі Firebase з
правилами `firestore.rules`: власник без входу, Аліса (власниця з входом,
дві фази), Богдан (друг із входом), гість без входу, Віка (друга оцінювачка).
Відсоток — наскільки це варто робити: 100 — обов'язково, 60–40 — на розсуд,
нижче — дрібниця.

## Що працює

- Оцінки, половинки, коментарі, зміна й зняття оцінки на чужому списку
  зберігаються й переносяться між усіма посиланнями того самого автора.
- Таблиця «Друзі» у власниці збіглася з тим, що поставили Богдан і Віка,
  клітинка в клітинку; зняті оцінки відсутні; стовпці друзів з'явились самі.
- Позначка «нове» засвічується й гасне після перегляду, не повертається.
- Перемикач видимості: вимкнено — друзі не бачать оцінок одне одного;
  увімкнено — бачать (після перезавантаження); хто вийшов з акаунта — не бачить;
  вимкнено знову — перестають бачити.
- HTML у коментарях показується як текст на всіх екранах.
- Вхід зі сторінки чужого списку повертає на той самий список.
- «Запам'ятати» працює й без входу; блок друзів у картці тайтла правильний.
- «Сформувати знову», видалення добірки, перевірки порожньої назви й вибору.
